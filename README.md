# Modificaciones

1. **Wonder Trade eliminado:** Se removió la función debido a la generación de Pokémon ilegales.
2. **Cambio de hardware:** Se deshabilitó temporalmente el uso de hardware real; actualmente se utiliza una **ESP32**.
3. **Búsqueda por partida guardada:** Se añadió soporte para cargar y buscar datos desde archivos de guardado (`.sav`).
4. **Respaldo automático:** Ahora se genera un *backup* del Pokémon intercambiado para evitar pérdida de datos.
5. **Mejora en la interfaz:** Ahora es posible arrastrar un Pokémon directamente desde las cajas al *slot* de intercambio.

## Créditos

Este proyecto se basa en el trabajo, librerías y desarrollo open-source del equipo y colaboradores de [GB-Link-Switch-LDN](https://github.com/GB-Link/GB-Link-Switch-LDN):

* **[GB-Link](https://github.com/GB-Link):** Desarrollo principal del ecosistema y adaptador de conexión.
* **tornadus / Kinnay:** Investigación, desarrollo base y lógica de red para emulación/tráfico de protocolo **LDN** (*Local Wireless Network* de Nintendo Switch).
* A la comunidad open-source por las herramientas de interconexión entre Game Boy/GBA y Nintendo Switch.
